# 来源、许可与上游参考

## Mo.s-Skill 自有内容

本仓库现有 18 份 Skill 正文：原有个人版 10 份、Mo’s 通用改写 2 份、MAT 职责方法 6 份。原十个个人版及 `mat-changelog-writer` 沿 [MIT License](<../LICENSE>)；其他七个改写包保留各自的上游许可和变更说明，不能把所有目录统称为原创 MIT。

源码归属、配套档位和实际安装分别判断：`own` 保留原十项，`recommended` 选择本仓库 `research-mos` 替换原研究方法；`For MAT` 按类型选择本地与上游方法，`all` 保留既有选择。完整范围以[分层清单](<分层清单.md>)及其来源清单为准，不用目录并集自动扩档。

新增方法是在用户确认的行为范围内改写，不复制整套上游库。各入口包含修改说明；单独分发须同时携带该目录的 `UPSTREAM.md`、许可文件及正文所引用的资源。

## 其他上游只记录来源，不整库分发

除上节明确授权的定向改写及必要许可文件外，本仓库不复制或重新发布第三方 Skill 正文。`manifests/` 记录来源选择和配套分配，不是安装器、锁定文件或运行权限配置：

- [recommended](<../manifests/recommended.json>) 用 `localSkills` 列出本仓库目录，`packages` 列出上游来源；本次替换原研究方法，个人代码审阅等选择不变。
- [For MAT](<../manifests/for-mat.json>) 用 `entries` 明列来源、类型及调用策略，分基础与手动专题；不自动继承日常推荐变化，不代表所有保留方法已完成接入。
- [all](<../manifests/all-used.json>) 保留既有的上游选择及排除项，仍与原 `own` 组合计数；本轮没有扩大该范围。

名称相同不代表来源相同：个人 `hunt` 来自 Waza，MAT `hunt` 来自本仓库的适配目录。按来源和路径区分，不能因本地出现同名目录就改写个人安装。上游真实版本、许可及安装方式仍以对应来源核验，清单不保证任何 Harness 都能用同一条命令安装。

## 维护上游索引

新增或修改 `manifests/` 条目之前，应完成以下核对：

1. 官方仓库或维护者发布页真实存在，且链接指向正确项目。
2. Skill 名称与上游当前目录或插件元数据一致。
3. 记录该来源的许可证，以及内容是否允许再分发。
4. 记录实际支持的 Agent 和官方安装路径，不把某一个工具的命令写成通用命令。
5. 来源索引更新不附带复制第三方正文、运行依赖或示例资产；独立改写须有明确范围、保留归属与许可。密钥配置不分发。

上游项目会改名、拆分、改变安装入口或删除 Skill。因此使用者应始终以官方说明为准；维护者需要定期复核来源索引，而不是把它当作长期稳定的包管理器。
